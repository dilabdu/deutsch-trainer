DEUTSCH TRAINER – ANDROID PWA STARTER

Bu birinchi ishlaydigan prototip. Android Chrome orqali ochib, menyudan
“Add to Home screen / Zum Startbildschirm hinzufügen” tanlang.

Muhim:
- Bu APK emas, o‘rnatiladigan web-ilova (PWA).
- Ilovani telefonga o‘rnatish uchun fayllarni HTTPS hostingga joylash kerak.
- Lug‘at hozircha shu brauzerning localStorage xotirasida saqlanadi.
- Ovoz tanish Web Speech API orqali; Android Chrome va Google nutq xizmati
  mavjudligi, internet va til qo‘llab-quvvatlashiga bog‘liq.
- Prototipda javobni avtomatik tekshirish matnni lug‘atdagi nemischa shakllar
  bilan solishtiradi. U talaffuz, grammatikani yoki sinonimning kontekstga
  mosligini professional tarzda baholamaydi.
- ChatGPT avtomatik tarjima API bilan ulanmagan: so‘zlarni ChatGPTda tayyorlab,
  JSON fayl ko‘rinishida import qilish mumkin.
